# Summary

The versioned and immutable principle requires identified desired-state versions that remain meaningful and retrievable. Moving references select versions but do not themselves provide immutable identity. Promotion should connect approved configuration with known artifacts and input versions. Audit and retention preserve accountability, while credentials follow a protected lifecycle. Rebuilding or resolving mutable dependencies can change content even when the visible release name remains the same.
