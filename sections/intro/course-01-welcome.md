# Welcome To The Course

This course is for learners preparing for the Certified GitOps Associate (CGOA) examination. It covers GitOps Principles, worth 30% of the published curriculum. The examination tests knowledge through multiple-choice questions. The explanations in this course build the reasoning needed to choose an answer, and the hands-on labs let you see each principle work on a real cluster.

At the end, you can explain the four GitOps principles: declarative, versioned and immutable, pulled automatically, and continuously reconciled. You can also run an Argo CD agent against a Git repository, change the repository, and read what the agent reports. Technical terms and acronyms are defined when they appear. Examples use a small set of example workloads named `scout`, `probe`, `shuttle` and `drifter`. The names identify workloads only and do not change the technical meaning.

Each section begins with an introduction and learning outcomes. Each module starts with a short map, continues with teaching parts, and ends with a summary. Every module has a playground, which is a clean Kubernetes cluster with Argo CD and a Git server that you can explore without any task, and a graded lab, which gives you a task and checks the result on the live cluster. Each section ends with a capstone lab and a knowledge check. A final knowledge check closes the course.

Read the examples carefully, identify which component does the work, and predict what changes when a condition changes. The practice questions are original and are not copied from the examination.
