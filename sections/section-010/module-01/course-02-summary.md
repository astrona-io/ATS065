# Summary

The declarative principle concerns what authoritative input means, not its filename. Intent should describe the required condition under a defined schema and management scope. Rendering can make higher-level input concrete, but its versions and parameters remain dependencies. Controllers implement that intent under ownership and policy. A stored command list can be versioned without becoming declarative, and a valid declaration can still request an unsafe or unrealizable condition.
