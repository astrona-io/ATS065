# Declarative

This section covers declarative. It develops sufficient Intent, Rendering And Controller Contracts through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Assess whether a declaration expresses sufficient managed intent.
- Explain rendering inputs and controller ownership.
- Distinguish declarative management from a script stored in version control.
