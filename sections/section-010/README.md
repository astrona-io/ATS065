# Declarative

This section covers the CGOA objective Declarative. It has one module, Declared State, Rendering And Controllers, with a playground, a graded lab, a capstone lab and a quiz. Argo CD is the reconciler and an in-cluster Gitea server is plumbing only. The labs and playgrounds were built without being run.

Read the landing page, the three parts and the summary in order. The playground stays open for the whole module. The graded lab follows part 2, and the capstone closes the section. The quiz comes last.

## Learning Outcomes

- Tell a declarative description from an ordered list of commands.
- Judge whether a declaration states enough intent and read how Kustomize renders it.
- Explain how the Argo CD controller marks, compares and prunes the objects it owns.
- Deliver two environments from one repository and retire an object by removing it from Git.
