# Declarative

This section covers the CGOA objective Declarative. It has three modules, Declared State, Rendering And Controllers, Declarative Formats, Idempotence And Apply Semantics and Repository Layout And Environment Design, each with a playground and a graded lab, plus a capstone lab and a quiz. Argo CD is the reconciler and an in-cluster Gitea server is plumbing only. The labs and playgrounds were built without being run.

Read each module in order: the landing page, the parts and the summary. Each graded lab follows the part that prepares it, and the capstone closes the section. The quiz comes last.

## Learning Outcomes

- Tell a declarative description from an ordered list of commands.
- Judge whether a declaration states enough intent and read how Kustomize renders it.
- Explain how the Argo CD controller marks, compares and prunes the objects it owns.
- Deliver two environments from one repository and retire an object by removing it from Git.
- Explain spec and status and which side belongs in Git.
- Compare create, apply and replace and describe idempotence.
- Explain server-side apply, field managers and conflicts.
- Render a Helm chart from declared values.
- Lay out repositories and environments with a base and overlays.
- Pass environment settings and validate a declaration before merge.
