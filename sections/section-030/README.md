# Pulled Automatically

This section covers the CGOA objective Pulled Automatically. It has one module, Pull, Credentials And Webhooks, with a playground, a graded lab, a capstone lab and a quiz. Argo CD is the reconciler and an in-cluster Gitea server is plumbing only. The labs and playgrounds were built without being run.

Read the landing page, the three parts and the summary in order. The graded lab follows part 2, and the capstone closes the section. The quiz comes last.

## Learning Outcomes

- Explain pull delivery and where the cluster access lives.
- Give Argo CD a least-privilege read credential for a private repository.
- Tell polling from webhooks and explain what a repository outage does.
- Set up pull, a webhook and a change through Git.
