# Summary

Automatic pulling gives the management agent independent access to authoritative desired state. Notifications can prompt earlier evaluation without becoming the only source of intent. The agent still needs source credentials, target authority and recoverable version selection. A CI job that directly applies payloads has a different control boundary. Pulling reduces some credential distribution but does not make repositories trustworthy or target permissions safe by default.
