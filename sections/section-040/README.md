# Continuously Reconciled

This section covers the CGOA objective Continuously Reconciled. It has one module, Drift, Refresh And Reconciliation, with a playground, a graded lab, a capstone lab and a quiz. Argo CD is the reconciler and an in-cluster Gitea server is plumbing only. The labs and playgrounds were built without being run.

Read the landing page, the three parts and the summary in order. The graded lab follows part 3, and the capstone closes the section. The quiz comes last.

## Learning Outcomes

- Define drift and tell sync status from health.
- Choose a sync policy with prune and self-heal and explain the defaults.
- Use a narrow ignore rule so two controllers do not fight.
- Bring up a cluster from one parent Application and retire a child through Git.
