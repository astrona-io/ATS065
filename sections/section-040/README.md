# Continuously Reconciled

This section covers continuously Reconciled. It develops drift, Refresh, Ignore Rules And Reconciliation Patterns through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Distinguish refresh and comparison from synchronization.
- Explain live drift and source-driven updates.
- Evaluate ignore-difference settings and controller-owned fields.
- Compare bootstrap composition with ApplicationSet-generated Applications.
